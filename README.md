# Dhruv Johri — Personal Portfolio

A responsive personal portfolio inspired by the structure of the uploaded iPortfolio template, customized with Dhruv's details, soft blue/teal styling, animations, and supplied profile photo.

## Files
- `index.html` — all portfolio sections and content
- `style.css` — layout, responsive design, visual styling, and animations
- `script.js` — mobile navigation, active section tracking, scroll reveals, type animation, project filters, and back-to-top
- `assets/profile.jpg` — profile photo supplied in the conversation

## Run locally
Keep the files together and open `index.html` in a browser. Google Fonts and Bootstrap Icons are loaded from CDNs, so those external assets require an internet connection; the layout and core interactions are implemented in the local files.

## Before publishing
- Add real GitHub repository URLs and live demos to individual projects when available.
- Update project status labels as projects are completed.
- Add a resume PDF if you want a resume download button.
- Verify every skill and project description before using this for applications.
- The contact link opens an email draft; it does not submit to a backend.

## Design
The template uses a left sidebar on desktop, a responsive slide-out sidebar on smaller screens, smooth section scrolling, subtle reveal and float animations, a typing headline, and category filters for projects. Reduced-motion preferences are respected.


### Interactive background
The portfolio includes a lightweight canvas particle field. Dots drift gently, connect to nearby dots, and respond subtly to pointer movement. The effect is disabled for users who prefer reduced motion and does not intercept clicks or scrolling.
